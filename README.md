Learnix Machine Learning Internship — Week 1

Exploratory Data Inspection

This project explores the Iris Flower Dataset as part of the Learnix Machine Learning Internship.

Objectives

Inspect feature column names and the target label.

Display the first five rows of the dataset.

Check the dataset shape and data types.

Identify missing values.

Calculate minimum, maximum, and average values using Pandas and NumPy.

Visualize petal measurements using a scatter plot and a histogram.

Dataset

The Iris dataset contains 150 flower samples, four numerical features, and three species classes: Setosa, Versicolor, and Virginica.

Technologies Used

Python

Pandas

NumPy

Matplotlib

Scikit-learn

Project Files

week1_exploratory_data_inspection.ipynb — Google Colab/Jupyter Notebook.

week1_eda.py — Python script version.

requirements.txt — Required Python packages.

How to Run

Open the notebook in Google Colab or Jupyter Notebook and run the cells from top to bottom.

For local execution, install the required packages:

python -m pip install -r requirements.txt

Expected Outcome

The project displays dataset information and statistical summaries, checks missing values, and generates a scatter plot and a histogram.

Conclusion

This project provides practical experience in exploratory data inspection, descriptive statistics, and data visualization—important first steps in a machine learning workflow.
